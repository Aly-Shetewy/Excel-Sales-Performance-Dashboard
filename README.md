# 📊 E-Commerce Sales & Delivery Performance Dashboard (Excel)

A comprehensive Microsoft Excel dashboard analyzing over **$1M+** in e-commerce sales, delivery fulfillment performance, and customer segmentation.

![Dashboard Screenshot](Sales%20dashboard.png)

## 🔑 Key Metrics & Insights
- **Total Revenue:** $1,011,481 generated across **125 orders**.
- **Average Order Value:** $10,263.
- **Top Sales Drivers:**
  - **Category:** Bed (سرير)
  - **Color:** White (أبيض)
  - **Location:** Cairo (القاهرة)
- **Platform Performance:** **Homzmart (هومزمارت)** led overall sales, accounting for over **$869K**.
- **Delivery Fulfillment:**
  - **80%** Orders successfully delivered.
  - **19%** Delivery failures.
  - **56%** Late deliveries vs **44%** On-time deliveries.
- **Customer Breakdown:** Analyzed B2B (**35 Companies**) vs B2C (**90 Individual customers**).

## 🛠️ Tools & Techniques Used
- **Data Cleaning & Structuring:** Prepared raw data for accurate analysis.
